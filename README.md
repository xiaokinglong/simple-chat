## 一个简单的聊天app

> 对接的是ollama本地跑的模型 qwen2.5:14b

### 🛠️ Tech Stack / 技术栈

- **Framework**: Next.js 16 (App Router)
- **Runtime & Language**: TypeScript
- **UI**: React 19, shadcn/ui, Radix UI, Tailwind CSS v4
- **Icons**: lucide-react
- **CSS Utilities**: class-variance-authority, tw-animate-css
- **Schema Validation**: Zod 4
- **Lint**: ESLint

npm run dev
